# BlackSoil ECI

基于 ECI 模型的黑土生态价值量化与资产化路径研究。

本项目已恢复中期数据、复现历史结果，并完成基于 SOC V10、正式黑土区边界和固定 0—30 cm 土层的分析。研究报告第一稿已完成；仓库先用于团队内部核查，后续完善论文及结项材料。

## 当前目录

- `data/raw/`：恢复的原始输入副本，暂不纳入 Git。
- `data/archive/`：历史结果与数据说明，暂不纳入 Git。
- `data/manifest.csv`：恢复文件的来源与校验值。
- `scripts/`：数据核查与分析脚本。
- `artifacts/`：核查表与新计算结果。
- `docs/`：方法决策和结果说明。
- `reports/`：经排版检查的研究报告 PDF 和可编辑 Word（发布包）。

## 研究范围

ECI 用于生态状态评价与排序。土壤碳储量独立核算，管理措施效应使用另行定义的处理与对照分析。收益以注明参数的情景测算表达。

主分析采用正式黑土区多边形、农田类别及完整 0—30 cm 土层。MAP 字段的物理单位仍有疑点，仅保留其源值进行背景评分与敏感性比较。原中期经纬度框选和旧结果保留在核查材料中。

## 复现状态

科学分析已在 Python 3.12、macOS 上运行验证。安装环境：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
```

下载版本化输入、核对 SHA-256，再运行：

```bash
python scripts/fetch_data.py
python scripts/run_project.py
python -m unittest discover -s tests -v
```

请先激活环境（macOS/Linux：`source .venv/bin/activate`；Windows：`.venv\Scripts\activate`），或将 `python` 替换为虚拟环境的完整路径。`run_project.py` 生成数据核查、固定深度分析、五张结果图和108组收益情景，不依赖本仓库上级目录的历史文件。原始输入不随仓库分发，来源、许可与手动下载位置见[数据获取与许可](docs/数据获取与许可.md)。源站可能限制自动下载；此时按脚本提示从官方页面下载并校验。边界压缩包需要支持 RAR 的系统 tar/bsdtar，或手动解压。

本地历史核查使用 `run_analysis.py` 与 `rerun_legacy.py`，后者依赖上级目录保留的中期脚本，不属于独立发布包的默认流程。报告排版还需要 python-docx、Pillow、文档渲染器和中文字体；它们不属于科学结果复算依赖。

2026年11月8日验证：8项单元检查通过；干净目录中使用六份已校验本地输入运行成功，9张核心CSV与当前结果在1e-10容差内一致。记录见 `artifacts/reproduction_validation.json`。尚未验证从空目录经全部源站自动下载成功，也未进行跨操作系统验证。

## 当前结果

固定深度共同样本为89个黑土区农田剖面，来自两条数据来源引用。0—30 cm SOC 储量中位数约68.64 tC/ha，三种赋权最低秩相关约0.977。这是非随机样本中的描述统计，不代表整个区域的总体均值、管理净增汇或可签发信用数量。

基准收益情景假设100 ha、0.3 tC/ha/年、100元/tCO₂、20%缓冲、70%农户分成，并计入核查及作业成本，农户净收益为−59.4元/ha/年，盈亏平衡价格约196.43元/tCO₂。这是明确参数的假设计算，不是观测收入或已签发信用。

当前样本来自两个来源条目和两个年份；SOC含量与储量存在相关性；MAP含义、管理措施编码和外部有效性仍有局限。赋权排序稳定不能替代区域代表性或因果识别。完整限制见[研究报告源稿](docs/研究报告.md)、[核查记录](docs/第一阶段数据与结果核查.md)和[方法修订记录](docs/方法修订记录.md)。
