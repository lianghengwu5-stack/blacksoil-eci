# 保护性耕作研究重构（2026-11-09）

此目录是新研究的独立原型，保留原项目结果。全国检索，东北黑土为核心实证，华北长期试验用于地域与时间尺度对照。不是全国代表性荟萃分析。

## 复现

在本目录用 Python 3 执行：

```sh
python3 analyze.py
python3 check_analysis.py
python3 analyze_agsy2024.py
```

计算仅使用标准库。`data/evidence.json`保存原文处理均值、数据口径、DOI/URL及关键限制。CSV是由代码生成的分析中间表，不是重复小区原始数据。`results/results.json`为完整结果。

`build_report.py`使用ReportLab生成审阅PDF，需要中文宋体字体（当前路径适用于macOS；其他系统须设置可用中文字体）。

## 指数的含义

主分析0–30 cm，SOC浓度与水稳性团聚体MWD各占一半；按厚度加权各层处理/对照的对数响应，再指数变换，对照为100。必须同时报告两个功能响应和所有负响应土层。权重0至1、不同深度及行内行间空间参照的敏感性已计算。

这是土壤保育两个功能的综合原型，不是全部生态质量、绝对健康等级或碳信用计量。尚未完成独立预测验证，不声称数学公式原创。

## 必须保留的限制

- 不用SOC浓度指数估算固碳收入。额外碳依据处理与对照同期碳储量变化之差另算。
- 公主岭来源的储量、固碳量、速率未完全对账；保留三种口径。估值不是可兑现碳现金流。
- 公主岭产量为干籽粒，不能直接乘商品粮收购价格。
- 齐齐哈尔CK是免耕处理，施有机肥的比较不归为耕作效应；毛利是扣所列投入后的试验口径。
- 基线官方调查没有识别耕作方式，不可当作已核实的常规耕作组。
- 新指数没有协方差数据，未生成伪置信区间。缺失字段保持缺失，不能补零。
- 地区、年份、实验不可拼接成一户真实农民。现行补贴上限不是历史试验实际收入。
- 补贴模型给出可识别部分及所缺参数，不能给出普遍最优金额。

## 长春全文及补充材料

用户已通过学校数据库提供DOI `10.1016/j.agsy.2024.103872`全文。6张数据表与方法已核对，新增`data/agsy2024.json`和`analyze_agsy2024.py`，输出长春试验预算、减排分解与算术审查。附表S1/S2已于2026年11月9日从出版商页面下载，转录于`data/agsy2024_supplement.json`，原文件保存在本地`sources/`。

长春2020年NT表5产值减材料成本=2221美元/公顷，表6 NEEB=2211；两种口径均保留。表4能量输出换算支持约2211，但只是交叉核算，不构成勘误证据。原文称NEEB和产量差异不显著。材料毛利不包含全部人工、机械、地租或秸秆机会成本。

该论文排放不包含SOC储量变化，土壤通量只测生长季；减排不是额外土壤固碳，不能与公主岭不同地块的碳估值相加。价格换算用论文自身6.4元/美元，碳价仅作2025年参考标尺。没有报告MWD，不为长春填造土壤指数。

## 补充材料整合版

`analyze_agsy2024.py`同时输出S1四项土壤浓度的处理对照响应、原文显著性字母以及两种预算口径的补偿临界值。S1仅为2020年0–20 cm，不直接与0–30 cm指数比较；不把浓度差异年化为固碳量。NT对CT改变耕作与秸秆处置两项，NT对MP则是在两者都还田条件下比较耕作体系；二者分别报告，不使用前者估计纯免耕效应。

补偿阈值记为材料毛利差。令U为遗漏新增成本、秸秆净机会成本、有依据的转型风险之和，减实际碳净现金和已受益的同类补贴，则新增损失补偿为max(0, U-材料毛利差)。U尚未观测，不能补零；阈值不是推荐的补贴金额，也不是公共生态服务支付上限。

已恢复上一版成果包中保存、但本地工作目录缺失的长春数据与脚本；覆盖前的工作文件备份在`tmp/pre_supplement_integration/`。最终PDF为`output/pdf/保护性耕作_补充材料整合研究稿.pdf`。成果包不包含出版商全文或附件，计算仅依赖转录JSON。

`archive_checks.py`是本地来源核验工具，需要未打包的出版商原文件及本版PDF；仅复现数值时不需要运行它。

## 研究稿与答辩整合版

2026-11-09完成六项核心研究的报告与论文整合稿。最新版位于 `output/manuscripts/`：研究报告11页、论文稿10页，各有PDF与可编辑DOCX。结项书7页保留在本地，因含学生编号与联系方式，不放入GitHub成果包。研究稿尚未经导师审定；论文未投稿。

可选图表与文稿生成：安装 `requirements-authoring.txt` 后依次运行 `make_figures.py`、`build_manuscripts.py`。正文来源保存在 `manuscript/`，图表输出PNG和SVG。字体默认macOS宋体，其他系统需在图表脚本设置可用中文字体。Word可直接打开；若通过LibreOffice导出PDF，须确保中文字体目录可见，且图片所在段落采用自动行距，避免裁切。数值复算无需字体或上述依赖。

`build_live_slides.mjs`保存可编辑Spaces答辩稿内容，需在Artifact Session已连接的演示文稿回调内执行三个批次；不是独立Node命令。云端文稿与本地研究稿对应13页答辩结构。源论文全文和补充材料原文件仅保存在本地。`data/screening_followup.json`记录新增文献的排除理由及济宁秸秆抵费例证，避免把干筛团聚体误当作水稳性指标或拼接不同年份小区。

成果包每个文件有SHA256清单。`package_release.py`在项目工作目录生成发布包并于全新临时目录复算所有结果，校验JSON/CSV逐字节一致；该打包脚本涉及本地来源归档，不属于数值复算必要文件。
