# 方法修订记录

## 研究对象

主分析采用作者发布的 SOC V10 数据，按刘宝元等（2021）黑土区矢量边界判断点位，再限定 `CLCD = Cropland`。典型黑土区边界用于范围敏感性。经纬度矩形筛选结果与 V9 结果保留为历史和范围对照。

黑土区是依据特定标志土壤划定的区域，区域内的农田样本不等于每个点都已完成土类鉴定。不得表述为全部点位均为实测典型黑土。

## 样本单位

剖面识别联合使用剖面编号、经纬度、采样年份和来源引用。不能仅按 `Profile` 合并：V10 的部分编号对应多个坐标或同一坐标多次记录。表层比较中对联合键仍不唯一的记录予以排除并留存清单。

固定深度主分析要求 0—30 cm 区间完整且无重叠，缺层、仅到 25 cm、无法区分的重复层不插补。SOC、NDVI、MAP、AI 同时要求有效。选择过程全部写入 `artifacts/fixed_depth/profile_selection.csv`。

## ECI 指标

固定深度版本使用五项指标：0—30 cm 厚度加权 SOC 含量、0—30 cm SOC 储量、NDVI、MAP 源值、AI。SOC 厚度加权均值为各层含量乘其落入目标区间的厚度之和除以 30 cm，不能称为等质量土壤比较。SOC 储量直接积分数据集提供的层储量，跨越 30 cm 的末层采用层内碳密度均匀假设。

三个赋权方案为等权、熵权、相关矩阵 PCA 载荷绝对值按解释方差加权。数据在本样本内按 1%—99% 缩尾、min–max 归一化。缩尾仅改变极值，不代表按土类识别并剔除泥炭土。

ECI 得分是样本内相对评价。更换样本后重新拟合的分数不能直接跨期或跨总体比较。当前没有证明 ECI 对管理行为贡献的因果效度、区域代表性或资产价格预测能力。

SOC 含量和储量存在相关与重复计权风险，需展示去掉任一碳指标的排序敏感性。NDVI 为植被背景，MAP、AI 为水分背景，均不能直接当作实测净碳汇或气候波动风险。原“状态—流量—风险”是目标框架，现有数据只实现部分代理。

## MAP 单位

V10 说明将 MAP 标为 mm，但东北源值的量级与年降水毫米存在疑点。现阶段保留源值，不擅自乘 10 或 12，不用其估计物理降水梯度、气候过程或 RothC 参数。

五指标评分对正比例单位换算不敏感：缩尾和 min–max 后正比例因子抵消。但这不能证明字段的物理含义正确，所以仍提供删除 MAP 的敏感性。

## 管理措施证据

TRACESoils 按处理和对照代码核对，单列未报告与可变方向，使用常规耕作对照子集另作汇总。符号检验忽略研究内相关、发表选择和效应量，最多作为探索性方向统计。

figshare 数据出自有机农业系统。含 till 字符的 49 条比较中，37 条为复合措施，12 条仅编码为 tillage。宽子集不能称作单一保护性耕作的纯效应，更不能直接套用于东北。

保留原观测级 DL 合并值以复现旧结果。新的研究级分析按 `study_code` 合并，并对未知研究内相关 rho=0、0.5、1 作敏感性，以保守修正 Hartung–Knapp t 区间呈现小研究数量的不确定性。它不是已恢复全部共享对照协方差的多层 Meta，也不能替代逐篇确认处理方向。

KBS 的 Table 4 对比 Conventional 和 Late successional 系统，2001 年不是共同干预前基线。原 2×2 差分只保留为外部系统对照示例，不作为保护性耕作因果主结论。重复地块匹配变化另外列出，避免将各期样本变化混入处理效应。

## SoilGrids

从留存的 API 原始返回逐层计算 SOC×容重×厚度，再求和，取代先平均属性再相乘。原 API 未查询粗砾体积分数，所得值未作粗砾修正。代表点分布与剖面样本没有逐点配对，且两套产品可能共享基础资料，因此只作量级比较，不称为独立验证精度或一致性相关系数。

## 资产化解释

存量不是新增碳信用。ECI 高分不能证明更高增汇潜力或监管额外性；保护高存量与选择增汇项目是两个决策。收益测算单独列假设增汇率、价格、缓冲、成本和分成，不从横截面碳储量或浓度 Meta 百分比直接推算年减排量。
