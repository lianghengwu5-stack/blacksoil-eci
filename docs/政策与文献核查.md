## 管理措施与推断

figshare 数据集提供的 SOC metadata 明确对比有机管理系统中采用某项或多项措施的处理与未采用相应措施的对照。它不是一个专门针对东北保护性耕作的原始面板。数据：https://doi.org/10.6084/m9.figshare.11983959.v4 ，关联论文：https://doi.org/10.1016/j.agee.2021.107356 。

KBS 数据说明明确其 Table 4 包含 Conventional 与 Late successional 系统的历史土样及后续样本。25年试验历史不代表本项目2001—2013年差分的观察间隔，也不证明2001年为措施实施前。数据：https://doi.org/10.5061/dryad.1rn8pk0x1 ，论文：https://doi.org/10.1016/j.geoderma.2024.117133 。

Meta 方法可依据 DerSimonian 与 Laird 原文（1986），https://doi.org/10.1016/0197-2456(86)90046-2 。作者后续论文指出研究数少、样本量高度不等时传统DL推断可能偏乐观：https://pmc.ncbi.nlm.nih.gov/articles/PMC4639420/ 。研究内相关敏感性属于本项目另加的分析假设，需在正文明确，不称为恢复了原始协方差。

原中期所引 He 等东北 Meta 的具体作者、效应量定义与适用范围仍需逐项核对，不直接继续引用“约4.17%”作为独立验证。
