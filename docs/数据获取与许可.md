# 数据获取与许可

## 版本与校验

`scripts/fetch_data.py` 列出六个主输入的版本化下载地址、引用和SHA-256。运行时只使用匹配的文件，不覆盖校验失败的既有文件。网站下载受限时，脚本报告应放置的位置，用户可从原始来源手动下载后重新校验。

```bash
python scripts/fetch_data.py
python scripts/run_project.py
python -m unittest discover -s tests -v
```

macOS 已验证系统tar可读取本项目RAR边界压缩包；Linux环境可使用libarchive提供的bsdtar。其他环境可手动将两个边界目录解压到 `data/raw/source_metadata/boundary/`。原始数据不随Git自动分发。

数据使用者应同时引用数据集和相关论文，并以各源站最新且适用于所用版本的许可为准。代码许可与第三方数据许可分别处理。当前仓库按用户要求保持私有，尚未决定代码的开源许可证。

## SoilGrids缓存

`data/external/soilgrids_queries.csv` 是项目中期保存的原始API返回副本，包含查询点位、坐标和属性载荷；分析逐层使用其中明确的换算因子。源站属性信息：https://www.isric.org/explore/soilgrids 。缓存文件保持原样，并在 `data/external/README.md` 记录校验值。

## 复现范围

`run_project.py` 生成论文与报告使用的新分析表和情景结果。历史脚本复现需要上级项目原中期目录，单独通过 `rerun_legacy.py` 执行；它不属于新克隆仓库的默认流程。

报告排版脚本使用本机文档运行环境和字体，不属于科学结果复算所需依赖。任何公开发布前，应再次检查数据许可、个人信息和尚未解决的方法问题。
